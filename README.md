# Loan Approval Analysis

## Project Overview
This project analyzes loan application data to understand the factors affecting loan approval. It uses Python for data cleaning and Exploratory Data Analysis (EDA), and Power BI for interactive dashboard visualization.

The dataset contains 614 loan applications with information about applicant demographics, income, loan amount, credit history, and property area.

## Tools & Technologies
- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Jupyter Notebook
- Power BI

## Project Files
| File | Description |
|---|---|
| Loan_approved.ipynb | Python data analysis notebook |
| loan_approved(1).csv | Original dataset |
| loan_approved_clean.csv | Cleaned dataset |
| Loan_Approval_FINAL_SAFE_DESIGNED.pbix | Power BI dashboard |
| Business Queries.pdf | Business questions and analysis objectives |

## Project Workflow
1. Data loading and initial inspection.
2. Data cleaning and missing-value handling.
3. Exploratory Data Analysis (EDA).
4. Visualization of applicant and loan information.
5. Analysis of loan approval patterns.
6. Power BI dashboard development.

## Key Analysis Areas
- Overall loan approval and rejection.
- Applicant demographics.
- Income and loan amount analysis.
- Property area comparison.
- Credit history and loan approval.
- Factors associated with loan rejection.

## How to Run
Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

Open the notebook:

```bash
jupyter notebook
```

Run `Loan_approved.ipynb` after keeping the dataset in the correct folder.
